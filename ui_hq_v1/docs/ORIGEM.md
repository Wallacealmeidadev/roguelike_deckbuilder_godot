# Origem dos assets

Arte raster criada com o gerador de imagens integrado, usando os estudos aprovados na conversa como referência de linguagem visual. Os atlas originais foram mantidos; os componentes são recortes declarados em recursos AtlasTexture.

As telas 01–10 são estudos raster. As telas 11–14 são composições determinísticas dos próprios componentes e fontes, com fonte SVG editável. Textos desses estudos não substituem o catálogo do jogo.

As instruções de geração disponíveis estão em `prompts.json`. Não foi utilizada a alternativa de geração por CLI/API.

Fontes distribuídas pelo repositório Google Fonts; licenças originais incluídas na pasta `fontes`:
- https://github.com/google/fonts/tree/main/ofl/bangers
- https://github.com/google/fonts/tree/main/ofl/barlowsemicondensed

Não foram incluídos sprites de Vega, Drone ou outros personagens. Ilustrações de punhos e escudo pertencem às cartas.
