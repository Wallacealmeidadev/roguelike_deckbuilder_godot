# Run das Docas Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tornar a run das Docas navegável em 11 nós, com estado persistente e regras do anexo.

**Architecture:** Evoluir `MapaRun` e fluxos de `main.gd`/`main.tscn`; `RunState` concentra estado durável e catálogos concentram dados. O combate existente resolve os encontros.

**Tech Stack:** Godot 4.7.2, GDScript tipado, GL Compatibility.

**Spec:** `docs/superpowers/specs/2026-09-28-run-docas-design.md`

## Global Constraints

- Sem redesign, assets, animações, novos inimigos, economia ou progressão meta.
- Onze nós percorridos; três blocos e Boss; uma bifurcação Elite/Desmanche que reconverge.
- Duas passagens e seed reproduzível; impedir apenas eventos consecutivos da mesma família.
- Preservar alterações locais do usuário; não reescrever combate, cartas ou mão.

## Review Focus

- Seed inválida/negativa não pode quebrar a geração.
- Um evento que inicia combate especial não pode concluir o nó antes da vitória.
- Clique repetido em prêmio/serviço não pode duplicar recompensa ou custo.
- Deck com cópias iguais deve permitir selecionar/remover/melhorar a cópia correta.
- Vitória do Boss provisório deve encerrar a run; derrota não deve marcar nó concluído.
